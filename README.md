A faster drop-in for make.fun's csv-reader 1.0.0: `solve.js` answers every CSV input exactly as csv-reader does — same columns, rows and broken-row errors — by cutting fields out with `indexOf` + `slice` instead of reading one character at a time.

## Run it

```sh
MAKEFUN_INPUT_DIR=./in MAKEFUN_OUTPUT_DIR=./out node main.ts
```
